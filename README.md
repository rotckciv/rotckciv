# Hi, I'm Viktor

I'm learning to build software with the help of AI. My focus is accessibility for blind and visually impaired users, including keyboard navigation and screen reader support.

## My first projects

- **AccessibleAudioShare** — Share microphone audio together with selected application or screen reader audio during calls.
- **YouTube Radio** — Discover and play music from YouTube, search for tracks, and manage favorites using keyboard controls.
- **Unigram Call Helper** — Control Unigram calls with global hotkeys and hear sound notifications when the group call participant count changes.

I'm still learning, and I welcome feedback on accessibility, usability, and bugs.
